What undoing does

Each product goes back to the quantity Amazon was showing immediately before batch {{ batch.id }} changed it. Those values were recorded from Amazon itself, not calculated, so this restores a state that genuinely existed.

The undo is recorded as a new batch rather than as an edit, so the history stays truthful — and the undo is itself undoable, which matters if the undo turns out to be the mistake.
